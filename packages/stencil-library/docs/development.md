## Environment and Setup

- **File:** [`environment-and-setup.md`](development/environment-and-setup.md)
- **Description:** This file provides detailed instructions for setting up the development environment. It includes guidelines on the required versions of Node.js, npm, Stencil.js, and Storybook, along with the installation of essential and additional tools. Common troubleshooting steps and the project structure are also covered.

---

## CSS Utilities

- **File:** [`css-utils.md`](development/css-utils.md)
- **Description:** This documentation outlines the process of developing and maintaining CSS class utilities within the design system. It includes details on utility types like spacing, typography, layout, colors, and shadows, as well as the automation scripts used for generating these utilities.

---

## Styling

- **File:** [`styling.md`](development/styling.md)
- **Description:** The `styling.md` file focuses on how PostCSS is utilized within the project for global and component-specific styling. It covers the configuration, plugins used, and the structure of global styles, as well as the challenges and solutions encountered in maintaining an efficient styling system.

---

## Documentation

- **File:** [`documentation.md`](development/documentation.md)
- **Description:** This file contains guidelines and best practices for documenting components within the design system. It explains the structure and content of various documentation files, the automation of documentation generation, and how to manually create and update documentation as needed.

---

## Testing

- **File:** [`testing.md`](development/testing.md)
- **Description:** This documentation covers the testing strategy for the design system, including unit tests, end-to-end tests, and coverage reporting. It provides instructions for setting up and running tests, as well as configuring testing frameworks like Jest.

---

## Scripts

- **File:** [`scripts.md`](development/scripts.md)
- **Description:** The `scripts.md` file lists and explains the various npm scripts used in the project. It includes build, watch, test, and documentation generation scripts, as well as details on how to customize or extend these scripts for specific development needs.

---

This catalog should help developers quickly locate and understand the purpose of each documentation file, ensuring that all aspects of the development process are well-documented and easily accessible.
