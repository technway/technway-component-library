## Overview

CSS class utilities in the Technway Design System are designed to provide a modular, scalable, and efficient way to apply consistent styles across components. These utilities are implemented using PostCSS and are divided into various categories such as spacing, typography, layout, colors, and shadows. 

The utilities are defined in `.pcss` files and are auto-generated or manually written based on the needs of the system. The goal is to maintain a clear separation between component-specific styles and global utilities that can be applied across multiple components.

---

## Directory Structure

### Location of Utility Files

The CSS Class Utilities are organized under the `src/globals/` directory. The key files include:

```
src/globals/
└─ utils/
   ├─ _a11y.pcss
   ├─ _borders.pcss
   ├─ _colors.pcss
   ├─ _layout.pcss
   ├─ _shadows.pcss
   ├─ _spacing.pcss
   └─ _typography.pcss
└─ components-utils.pcss
└─ utils.pcss
└─ utils.css
```

- **`utils/` Directory**: Contains PostCSS files that define utility classes for various aspects of design, such as accessibility, borders, colors, layout, shadows, spacing, and typography.
- **`components-utils.pcss`**: Includes utility classes that are specifically used within component styles. These utilities are scoped to components to prevent unnecessary global styles.
- **`utils.pcss`**: The primary file that contains general-purpose utility classes not directly tied to any particular component. This file is the main source for generating the `utils.css` file.
- **`utils.css`**: This is the output file generated by the build process, containing all the compiled utilities along with responsive breakpoints.

### CSS Utility File Breakdown

Each utility file within the `utils/` directory serves a specific purpose:

- **`_a11y.pcss`**: Contains utility classes related to accessibility, such as visually hidden elements, focus states, and ARIA attribute management.
- **`_borders.pcss`**: Defines border utilities, including classes for border-width, border-color, and border-style.
- **`_colors.pcss`**: Houses color utility classes for text, backgrounds, borders, and other elements. These classes are derived from the design system’s color palette.
- **`_layout.pcss`**: Provides layout-related utilities such as display, positioning, and flexbox/grid configurations.
- **`_shadows.pcss`**: Contains utility classes for applying box shadows and text shadows to elements.
- **`_spacing.pcss`**: Includes utilities for margin and padding, allowing consistent spacing across elements.
- **`_typography.pcss`**: Defines typography-related utilities, including font size, font weight, text alignment, and text transformations.

## Generating CSS Utilities

### Custom Script: `css-utils.js`

A custom script located at `scripts/css-utils.js` is responsible for generating the final `utils.css` file, which includes both the basic utilities and their responsive counterparts.

#### Purpose of the Script

- **Breakpoint Generation**: The script automatically creates media queries for each utility class across multiple breakpoints, ensuring responsive behavior without manual intervention.
- **Optimization**: By generating only the necessary utilities and including them in `utils.css`, the overall size of the CSS file is reduced, preventing unused styles from bloating the final output.

#### Script Workflow

1. **Input Source**: The script reads from `utils.pcss`, which contains the base utility classes.
2. **Breakpoint Processing**: The script dynamically generates media queries for the defined breakpoints and applies them to the utility classes.
3. **Output Generation**: The script outputs a compiled `utils.css` file that includes both the base classes and the breakpoint-specific classes.

#### Running the Script

To generate the CSS utilities, you can use the following npm script:

```bash
npm run build:css-utils
```

This command will run the `css-utils.js` script, producing the `utils.css` file in the `src/globals/` directory.

#### Adding New Utilities

To add a new utility class:

1. **Create the Utility in `utils.pcss`**: Define the base utility class in `utils.pcss` or the relevant file under `utils/`.
2. **Run the Build Script**: Execute `npm run build:css-utils` to include the new utility in `utils.css`.

## Best Practices

- **Consistency in Naming**: Maintain consistent naming conventions for all utility classes to avoid confusion and ensure they are easy to remember and use.
- **Use Variables for Reusability**: Always rely on CSS variables defined in variables.pcss to ensure consistency and flexibility across the design system.
- **Limit Utility Overload**: Only create utilities that are necessary and will be used across multiple components. This avoids bloating the CSS files with unused styles.
- **Test Thoroughly**: Every utility, especially those generated automatically, should be thoroughly tested to ensure they work as intended across various components and screen sizes.
