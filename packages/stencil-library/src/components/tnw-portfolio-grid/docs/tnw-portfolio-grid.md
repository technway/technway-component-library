| Property | Description | Default | Type |

| **itemsData** | <div>JSON string containing the grid items data. Each item includes required `src` and `alt` (string), and optional `link` (string), `rowStart` (number), `rowEnd` (number), `colStart` (number), and `colEnd` (number).</div> | N/A | `string` |
