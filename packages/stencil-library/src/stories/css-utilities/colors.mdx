## Introduction

Color utilities are fundamental in ensuring that your design system is both consistent and flexible. By using custom properties, color utilities allow for easy adaptation to various branding requirements while maintaining a unified look and feel across your application. These utilities cover a wide range of colors, including primary, secondary, background, and utility colors like success, warning, and danger.

To see the colors, visit the [Tokens Colors documentation](#tokens-colors).

## Text Color Utilities

Text color utilities provide classes for setting the color of text elements. Each utility applies a specific color from the design system’s palette.

### Usage

<Markdown>
{`
| Utility Class        | Description                             |
| -------------------- | --------------------------------------- |
| \`.color-primary\`     | Applies the primary brand color to text |
| \`.color-secondary\`   | Applies the secondary color to text     |
| \`.color-auto\`        | Applies the default text color          |
| \`.color-inverse\`     | Applies the inverse text color          |
| \`.color-200\`       | Applies a lighter text color            |
| \`.color-placeholder\` | Applies the placeholder text color      |
| \`.color-white\`       | Applies white color to text             |
| \`.color-black\`       | Applies black color to text             |
`}
</Markdown>


### Examples

<Source
language="html"
code={`
<p class="color-primary">Primary Text Color</p>
<p class="color-secondary">Secondary Text Color</p>
<p class="color-auto">Default Text Color</p>
<p class="color-inverse">Inverse Text Color</p>
<p class="color-200">Light Text Color</p>
<p class="color-placeholder">Placeholder Text Color</p>
<p class="color-white bg-black p-md">White Text on Black Background</p>
`}
dark={true}
/>

These classes ensure that text elements maintain a consistent color scheme throughout the application.

## Customization and Theming

Customization and theming are simplified through the use of custom properties. By overriding these properties, it’s possible to adjust the color scheme to match specific branding requirements or to adapt the design system to different projects.

### Theming Variables

The following callback variables are used for theming and can be customized to change the appearance of your application:

<Markdown>
{`
| Variable Name           | Description                                     |
| ----------------------- | ----------------------------------------------- |
| \`--primary-color\`       | Main primary color                              |
| \`--primary-color-400\`| Darker shade of primary color                   |
| \`--primary-color-300\`| Lighter shade of primary color                 |
| \`--primary-color-200\`    | Lighter tone of primary color                            |
| \`--primary-color-100\` | Lightest tone of primary color                           |
| \`--primary-color-opacity\`  | Primary color with opacity                               |
| \`--secondary-color\`        | Main secondary color                                     |
| \`--secondary-color-400\` | Darker shade of secondary color                          |
| \`--secondary-color-300\`| Lighter shade of secondary color                         |
| \`--secondary-color-200\`  | Lighter tone of secondary color                          |
| \`--secondary-color-100\`| Lightest tone of secondary color                        |
| \`--secondary-color-opacity\`| Secondary color with opacity                             |
| \`--background-color\`              | Default background color                                  |
| \`--background-color-200\`        | Lighter shade of background color                         |
| \`--background-color-inverse\`      | Inverse background color (e.g., black for light themes)   |
| \`--background-color-opacity\`      | Background color with opacity                             |
| \`--text-color\`            | Default text color                                        |
| \`--text-color-inverse\`    | Inverse text color (e.g., white for dark backgrounds)     |
| \`--text-color-light\`      | Lighter text color                                        |
| \`--success-color\`         | Success color                                             |
| \`--warning-color\`         | Warning color                                             |
| \`--danger-color\`          | Danger color                                              |
| \`--info-color\`            | Informational color                                       |
| \`--border-color\`          | Default border color                                      |
| \`--border-color-inverse\`  | Inverse border color                                      |
| \`--border-color-opacity\`    | Light border color                                        |
| \`--placeholder-color\`     | Default placeholder color                                 |
`}
</Markdown>

### Theming Considerations for Inverse Colors

Inverse colors are typically used together to create a visually consistent experience across different themes. When using an inverse background, such as a dark background for a light theme, it is important to also use inverse text colors to ensure readability.

For example:

<Source
language="html"
code={`
<div class="bg-inverse text-white p-md">
  This is an inverse background with white text.
</div>
`}
dark={true}
/>

This ensures that the text is readable against the darker background. Similarly, inverse border and placeholder colors should be used in conjunction with inverse backgrounds to maintain a cohesive design.

## Usage Guidelines

- **Consistency:** Ensure that color utilities are used consistently throughout the application to maintain a cohesive design.
- **Accessibility:** Consider contrast ratios and readability when applying color utilities, especially for text and background colors.
- **Customization:** Use the custom properties to easily theme and adjust the color scheme for different projects or branding requirements.

## Frequently Asked Questions (FAQ)

### Can color values be customized?

Yes, color values can be customized by overriding the respective custom properties (e.g., `--primary-color`).

### How do I ensure accessibility with color utilities?

Ensure that color combinations meet contrast ratio guidelines, especially for text and background colors, to maintain accessibility.

### What is the best way to apply color utilities?

Use color utilities to reinforce the design system’s color scheme, maintain visual consistency, and ensure accessibility across the UI.

## Conclusion

Color utilities are a foundational aspect of the design system, enabling a consistent and adaptable visual language across applications. By leveraging custom properties, these utilities offer flexibility in theming and ensure that the design remains cohesive, accessible, and easily maintainable.
