## Introduction

The layout utilities in this design system allow you to create complex layouts using simple, reusable classes. These classes are built on top of CSS display properties, flexbox, grid systems, and other essential layout properties like width, height, object positioning, and more.

---

## Display Utilities

Display utilities allow you to control the display properties of elements, which is the foundation for all other layout utilities like flexbox and grid.

### Usage

<Markdown>
{`
| Utility Class       | Description                                       |
| ------------------- | ------------------------------------------------- |
| \`.inline-block\`    | Sets the display property to inline-block          |
| \`.flex\`           | Sets the display property to flex                  |
| \`.inline-flex\`     | Sets the display property to inline-flex           |
| \`.grid\`           | Sets the display property to grid                  |
| \`.hidden\`         | Sets the display property to none (hides element)  |
`}
</Markdown>

### Examples

<Source
language="html"
code={`
<div class="flex">This element uses flex display.</div>

<div class="grid">This element uses grid display.</div>

<div class="hidden">This element is hidden.</div>
`}
dark={true}
/>

These utilities form the basis for creating responsive and flexible layouts using flexbox and grid systems.

## Flexbox Utilities

Flexbox utilities allow you to control the alignment, direction, and wrapping of flexbox layouts. After setting the display to `flex`, these utilities give you control over the flex container's behavior.

### Usage

<Markdown>
{`
| Utility Class                  | Description                                               |
| ------------------------------ | --------------------------------------------------------- |
| \`.flex-direction-row\`          | Sets the direction of flex items to row                   |
| \`.flex-direction-column\`       | Sets the direction of flex items to column                |
| \`.flex-direction-row-inverse\`  | Sets the direction of flex items to row-reverse           |
| \`.flex-direction-column-inverse\`| Sets the direction of flex items to column-reverse       |
| \`.flex-wrap-wrap\`              | Controls whether flex items wrap                          |
| \`.flex-wrap-nowrap\`            | Prevents flex items from wrapping                         |
| \`.justify-content-start\`       | Aligns flex items along the main axis at the start        |
| \`.justify-content-end\`         | Aligns flex items along the main axis at the end          |
| \`.justify-content-center\`      | Aligns flex items along the main axis at the center       |
| \`.justify-content-between\`     | Distributes flex items with space between them            |
| \`.justify-content-around\`      | Distributes flex items with space around them             |
| \`.align-items-start\`           | Aligns flex items along the cross axis at the start       |
| \`.align-items-end\`             | Aligns flex items along the cross axis at the end         |
| \`.align-items-center\`          | Aligns flex items along the cross axis at the center      |
| \`.align-items-baseline\`        | Aligns flex items along the cross axis at the baseline    |
| \`.align-items-stretch\`         | Stretches flex items to fill the cross axis               |
`}
</Markdown>

### Examples

<Source
language="html"
code={`
<div class="flex flex-direction-row justify-content-between align-items-center">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>
`}
dark={true}
/>

These utilities are crucial for creating responsive and flexible layouts using flexbox.

## Object Fit Utilities

Object fit utilities allow you to control how an element fits within its container, using the object-fit property.

### Usage

<Markdown>
{`
| Utility Class      | Description                                           |
| ------------------ | ----------------------------------------------------- |
| \`.fit-fill\`       | Stretches the object to fill the container             |
| \`.fit-contain\`    | Resizes the object to be fully contained within the container |
| \`.fit-cover\`      | Resizes the object to cover the container              |
| \`.fit-none\`       | Displays the object at its intrinsic size               |
| \`.fit-scale-down\` | Scales the object down to fit the container            |
`}
</Markdown>

### Examples

<Source
language="html"
code={`
<img src="image.png" class="fit-cover" alt="Cover fitted image" />
`}
dark={true}
/>
