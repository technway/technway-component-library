# Spacing Utilities

Spacing utilities are fundamental for creating consistent and well-structured layouts. This documentation outlines the available utilities for margins, paddings, gaps, and positional spacing. Each utility class is derived from custom properties, allowing for easy theming and consistent application across projects.

## Introduction

Spacing utilities are essential in maintaining the structure and rhythm of a design system. By using custom properties, these utilities allow for consistent spacing throughout your application, ensuring a cohesive look and feel across different components.

---

## Margin Utilities

Margin utilities provide classes for applying margin spacing to elements. Each utility applies a specific margin value from the design system’s spacing palette.

### Usage

<Markdown>
{`
| Utility Class | Description                          |
| ------------- | ------------------------------------ |
| \`.m-[size]\`  | Applies margin to all sides           |
| \`.mt-[size]\` | Applies margin to the top             |
| \`.mb-[size]\` | Applies margin to the bottom          |
| \`.mr-[size]\` | Applies margin to the right           |
| \`.ml-[size]\` | Applies margin to the left            |
| \`.minl-[size]\` | Applies margin inline                |
| \`.minls-[size]\` | Applies margin inline start          |
| \`.minle-[size]\` | Applies margin inline end            |
| \`.mblk-[size]\` | Applies margin block                 |
| \`.mblks-[size]\` | Applies margin block start           |
| \`.mblke-[size]\` | Applies margin block end             |
`}
</Markdown>

### Examples

<Source
language="html"
code={`
<div class="m-md">Margin on all sides</div>
<div class="mt-lg">Margin on top</div>
<div class="ml-2xs">Margin on left</div>
<div class="minl-xs">Inline margin</div>
`}
dark={true}
/>

## Customization and Theming

Customization and theming are simplified through the use of custom properties. By overriding these properties, it’s possible to adjust the spacing scheme to match specific branding requirements or to adapt the design system to different projects.

### Theming Variables

The following callback variables are used for theming and can be customized to change the appearance of spacing in your application:

<Markdown>
{`
| Variable Name          | Description                                    |
| ---------------------- | ---------------------------------------------- |
| \`--spacing-none\`      | No spacing                                     |
| \`--spacing-2xs\`       | Extra-extra small spacing (5px)                |
| \`--spacing-xs\`        | Extra small spacing (10px)                     |
| \`--spacing-sm\`        | Small spacing (15px)                           |
| \`--spacing-md\`        | Medium spacing (20px)                          |
| \`--spacing-lg\`        | Large spacing (40px)                           |
| \`--spacing-xl\`        | Extra-large spacing (55px)                     |
| \`--spacing-2xl\`       | Extra-extra large spacing (70px)               |
| \`--spacing-3xl\`       | Triple extra-large spacing (90px)              |
| \`--spacing-4xl\`       | Quadruple extra-large spacing (120px)          |
`}
</Markdown>

## Usage Guidelines

- **Consistency:** Ensure that spacing utilities are used consistently throughout the application to maintain a cohesive design.
- **Accessibility:** Consider readability and usability when applying spacing utilities, ensuring that content is neither too cramped nor too spaced out.
- **Customization:** Use the custom properties to easily theme and adjust the spacing scheme for different projects or branding requirements.

## Frequently Asked Questions (FAQ)

### Can spacing values be customized?

Yes, spacing values can be customized by overriding the respective custom properties (e.g., `--spacing-md`).

### How do I ensure accessibility with spacing utilities?

Ensure that spacing provides sufficient whitespace for readability without causing content to appear disjointed or difficult to navigate.

### What is the best way to apply spacing utilities?

Use spacing utilities to reinforce the design system’s layout structure, maintain visual consistency, and ensure a pleasant user experience across the UI.
