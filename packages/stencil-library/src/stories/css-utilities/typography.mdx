## Font Size Utilities

Font size utilities allow you to apply various font sizes to text elements, ensuring a consistent text hierarchy.

### Usage

<Markdown>
{`
| Utility Class       | Description                                     |
| ------------------- | ----------------------------------------------- |
| \`.fs-[size]\`        | Applies font size based on the defined sizes    |
| \`.fs-heading\`       | Applies the default heading font size           |
| \`.fs-text\`          | Applies the default text font size              |
`}
</Markdown>

### Examples

<Source
language="html"
code={`
<p class="fs-md">Medium Font Size</p>
<p class="fs-xl">Extra Large Font Size</p>
<p class="fs-heading">Heading Font Size</p>
<p class="fs-text">Text Font Size</p>
`}
dark={true}
/>

## Customization and Theming

Customization and theming of typography utilities are easily managed through the use of custom properties. By overriding these properties, you can tailor typography to fit specific branding or project requirements.

### Theming Variables

The following callback variables are used for theming and can be customized to change the typography of your application:

<Markdown>
{`
| Variable Name              | Description                                           |
| -------------------------- | ----------------------------------------------------- |
| \`--fs-[size]\`               | Defines the font size for the specified size category  |
| \`--fw-[weight]\`             | Defines the font weight for the specified weight value |
| \`--lh-[value]\`              | Defines the line height for the specified value       |
| \`--font-heading\`            | Defines the font family for headings                 |
| \`--font-text\`               | Defines the font family for text                    |
| \`--font-icon\`               | Defines the font family for icons                   |
`}
</Markdown>

This approach ensures that typography can be adapted to various project needs while maintaining a consistent look and feel across the application.

## Frequently Asked Questions (FAQ)

### Can typography values be customized?

Yes, typography values can be customized by overriding the respective custom properties (e.g., `--fs-md`).

### How do I ensure accessibility with typography utilities?

Ensure that font sizes and line heights are adequate for readability and consider using larger sizes for small text on smaller screens.

### What is the best way to apply typography utilities?

Use typography utilities to reinforce the design system’s visual hierarchy, maintain readability, and ensure a pleasant user experience across the UI.
