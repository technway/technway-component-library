## Introduction

The Technway Design System employs CSS variables to manage colors consistently across your project. These variables are defined globally and can be overridden to create custom themes or adjust specific component colors.

### Default Color Variables

Below is a snippet of the core color variables and their corresponding callback variables used in the design system:

## Customizing Global Colors

To customize global colors across your project, override the default color variables in your global CSS or theme-specific files.

### Example: Customizing Primary and Secondary Colors

To adjust the primary and secondary colors throughout your application:

<Source
code={`
:root {${`\n`}
  --primary-color: #004085;${`\n`}
  --secondary-color: #6c757d;${`\n`}
}
`}
language="css"
dark={true}
/>

By overriding `--primary-color` and `--secondary-color`, you modify the appearance of all components that utilize the `tnw-primary-color` and `--tnw-secondary-color` tokens.

---

## Best Practices for Color Customization

- **Consistency**: Always use global variables (`--tnw-...`) to ensure uniformity across your project.
- **Accessibility**: Ensure adequate color contrast for readability and accessibility.
- **Variable Reuse**: Avoid hardcoding colors directly in components; leverage CSS variables instead.
- **Cross-Theme Testing**: Test your colors in different themes (e.g., light and dark) to ensure a consistent user experience.
