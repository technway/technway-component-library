## Introduction

The Technway Design System uses a variety of CSS variables to control typography, including font families, sizes, weights, and line heights. These variables are defined globally and can be customized to meet specific needs.

## Customizing Global Typography

To customize the typography across the project, override the default typography variables in global CSS or theme-specific files.

### Example: Customizing Font Families and Sizes

To adjust the font family and size used for headings and text throughout the application:

<Source
code={`
:root {${`\n`}
  --font-heading-en: 'Roboto', sans-serif;${`\n`}
  --fs-heading: 32px;${`\n`}
}
`}
language="css"
dark={true}
/>

By overriding `--font-heading-en` and `--fs-heading`, the appearance of all headings that use the `tnw-font-heading` and `tnw-fs-heading` tokens will be changed.

---

## Best Practices for Typography Customization

- **Consistency**: Global variables (`--tnw-...`) should always be used to ensure uniformity across the project.
- **Accessibility**: Font sizes and line heights should be designed to provide adequate readability.
- **Variable Reuse**: Hardcoding font properties directly in components should be avoided; CSS variables should be leveraged instead.
- **Cross-Device Testing**: Typography should be validated on different screen sizes and resolutions to ensure a consistent user experience.
